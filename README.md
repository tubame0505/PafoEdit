# PafoEdit

1行の表示幅を半角20列に固定した、プレーンテキスト専用のGUIエディタ。ファイル入出力は持たず、クリップボードだけを外部との窓口にする。

![preview](docs/preview.png)

## 挙動

- 等幅フォント `Noto Sans Mono CJK JP` 16pt で固定表示（折り返しなし、横スクロール）。
- 行ごとに半角20列まで。超えた文字は警告色（琥珀）の背景で示す。制限は目安で、入力・貼り付けは制限しない。
- 20列の境界に破線のガイドを表示する。
- 空白はセル内に点線の□で表示する（半角 `U+0020` と全角 `U+3000`、セル幅に合わせた大きさ）。
- タブ文字は入力できない（`Tab`/`Shift+Tab` は何もしない）。貼り付けに含まれるタブは半角4空白に置換する。
- 保存・読込・メニュー・検索は無い。`Ctrl+C/V/X`、undo/redo、選択、IME は Qt 標準の動作。

### 列の数え方

| 文字 | 列数 |
|---|---|
| 半角英数・記号、半角空白、幅の曖昧な文字（`①` `→` など） | 1 |
| 全角（`あ` `漢` `Ａ` `　` など、東アジア幅 W/F） | 2 |
| 結合文字・書式文字（`U+0301`、`U+200D` など） | 0 |
| 改行 | 数えない（行ごとにリセット） |

全角文字が20列目に食い込む場合は、その文字全体を超過として着色する。

## 必要環境

- Python 3.10 以上
- PySide6（開発時は 6.12 / Qt 6.12）
- フォント `Noto Sans Mono CJK JP`（Arch: `noto-fonts-cjk`）。見つからない場合は代替フォントで起動し、stderr に警告を出す。

## 起動

```sh
python3 pafoedit.py
```

## フォントの変更

`pafoedit.py` 先頭の定数を書き換える。全角幅が半角幅の2倍でないフォントでは、起動時に警告が出る（グリッドが崩れるため）。

```python
FONT_FAMILY = "Noto Sans Mono CJK JP"
FONT_POINT_SIZE = 16
```

## テスト

```sh
python3 -m unittest -v
```

列数計算と超過判定（境界値・全角の食い込み・結合文字）を検証する。GUI の描画は、表示先の無い環境では offscreen プラットフォームで画像化して確認する:

```sh
QT_QPA_PLATFORM=offscreen python3 pafoedit.py   # 起動確認（Ctrl+C で終了）
```

## 制限

- 実セッションでの IME 変換とシステムクリップボードは未検証（X11/Wayland のある環境で確認すること）。
- ウィンドウサイズは目安。狭くすると横スクロールになる。
